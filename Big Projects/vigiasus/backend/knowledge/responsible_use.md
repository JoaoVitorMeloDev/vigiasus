# Uso responsável e evolução

Uma pesquisa futura precisaria de dados oficiais adequados, documentação de licenças, avaliação de qualidade, aprovação institucional quando necessária e colaboração com profissionais de vigilância. Dados pessoais de saúde não devem ser publicados ou adicionados a esta demonstração.

Qualquer estudo deve usar agregação e minimização de dados, avaliar vieses territoriais e temporais, separar treino e validação no tempo e comparar o método com uma linha de base. A utilidade deve ser avaliada com profissionais e comunidades afetadas antes de considerar uso operacional.

O RAG recupera trechos dos documentos Markdown locais e retorna os nomes dos arquivos usados como fonte. Sem Ollama, o serviço apenas recupera e apresenta trechos; não gera uma resposta de modelo de linguagem. Com Ollama configurado, a geração é solicitada com contexto recuperado e restrições explícitas, mas ainda pode errar e precisa de revisão.

O servidor MCP disponibiliza ferramentas para consultar os mesmos dados demonstrativos e pesquisar a documentação do projeto. Uma ferramenta MCP não transforma os dados sintéticos em evidência oficial.
